# スカイライン・テクノロジー 企業サイト

スカイライン・テクノロジー株式会社（架空の企業）のコーポレートサイトです。
「ソフトウェアを、街のように高く、確かに。」をコンセプトに、高層ビル街をモチーフにしたデザインで構成した1ページのサイトです。

## サイトの概要

| セクション | 内容 |
| --- | --- |
| トップ（ヒーロー） | キャッチコピーと、ビル街のアニメーション（Canvas描画） |
| フロアガイド | 提供サービス（DXコンサルティング、業務システム受託開発、モバイル・Webアプリ、クラウド基盤・SRE） |
| 建てるように、つくる | 開発プロセス（地盤調査 → 設計 → 施工 → 竣工検査 → 保守・改修） |
| 導入実績 | 導入事例の紹介 |
| 会社概要 | 代表メッセージと会社情報 |
| 採用情報 | 採用募集の案内 |
| お問い合わせ | お問い合わせフォーム |

### 特徴

- HTML・CSS・JavaScript を `index.html` の1ファイルにまとめているため、ビルドやインストールは不要です。
- ライトモードとダークモードの両方に対応しています（OSの設定に従います）。
- `prefers-reduced-motion` を設定している環境では、アニメーションを抑えます。
- お問い合わせフォームは**デモ**です。入力チェックは行いますが、内容はどこにも送信されません。

## ファイル構成

```
company-site/
├── index.html   # サイト本体（HTML・CSS・JavaScript）
└── README.md    # このファイル
```

## ブラウザで index.html を開く手順

### 方法1：ファイルを直接開く

1. Finder（Windows の場合はエクスプローラー）で `company-site` フォルダを開きます。
2. `index.html` をダブルクリックします。
3. 既定のブラウザでサイトが表示されます。

ほかのブラウザで開きたい場合は、`index.html` をブラウザのウィンドウにドラッグ＆ドロップしてください。

### 方法2：ターミナルから開く

`company-site` フォルダに移動してから、OSに合ったコマンドを実行します。

```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

### 方法3：ローカルサーバーで開く（任意）

`http://` のURLで確認したい場合は、簡易サーバーを起動します（Python 3 が必要です）。

```bash
python3 -m http.server 8000
```

ブラウザで <http://localhost:8000> を開きます。終了するときは、ターミナルで `Ctrl + C` を押してください。

## 補足

- フォントは Google Fonts から読み込んでいます。オフラインで開いた場合は、代わりのフォントで表示されます。
